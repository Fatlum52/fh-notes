# WHERE - ViewModel Overview

## 4+1 View Model

- **Logical View**: zeigt logische struktur des systems
- **Development View**: zeigt struktur aus entwickler-sicht
- **Process View**: zeigt laufzeit-verhalten
- **Physical View**: zeigt deployment und infrastructure
- **Scenarios**: use cases die views verbinden

## Wichtige Views

- logical view: klassen, interfaces, beziehungen
- development view: packages, modules, komponenten
- process view: prozesse, threads, interaktionen
- physical view: server, netzwerk, hardware
